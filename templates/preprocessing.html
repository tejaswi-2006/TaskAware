Leakage-Safe Preprocessing

All preprocessing is applied inside a scikit-learn Pipeline + ColumnTransformer.

The transformations (imputation, encoding, scaling) are fitted only on the training fold . The test fold is transformed using the already-fitted transformer.

TaskAware never fits preprocessing on the full dataset before splitting, because that would leak information from the test set into the training data.
